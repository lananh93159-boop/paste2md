快速开始

安装非常简单：

npm install -g paste2md

然后使用：

pbpaste | paste2md > post.md

更多示例

# 转换 HTML 文件
paste2md -i article.html -o article.md

# 从剪贴板读取，复制到剪贴板
paste2md -c --copy

# 删除所有链接
pbpaste | paste2md --strip-links
